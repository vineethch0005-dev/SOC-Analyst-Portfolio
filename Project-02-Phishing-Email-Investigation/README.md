
# Project 02: Phishing Email Investigation

## Project Overview
A simulated SOC L1 investigation of a suspicious email reported by an employee.

## Scenario
An employee receives an unexpected email claiming to be from the IT support team. The email asks the employee to verify their account through a suspicious link and contains an unexpected attachment.

## Objectives
- Identify suspicious sender details.
- Analyze email headers.
- Examine suspicious URLs safely.
- Identify potential attachment risks.
- Identify Indicators of Compromise (IOCs).
- Classify and document the security incident.

## Tools and Skills
- Microsoft Excel
- Email header analysis concepts
- URL analysis concepts
- VirusTotal (optional, for safe analysis of known public indicators)
- SOC incident investigation and documentation

## Investigation Steps
1. Review the reported email.
2. Examine sender and reply-to addresses.
3. Analyze SPF, DKIM and DMARC results if available.
4. Identify suspicious links and attachments.
5. Extract relevant IOCs.
6. Assess the phishing risk.
7. Recommend containment and escalation actions.

## Expected Deliverables
- Simulated phishing email
- Email investigation notes
- IOC analysis
- Findings report
- SOC incident report

## Important Note
All email content and indicators in this project are simulated for educational purposes. No real phishing messages, malicious attachments or live malicious URLs are used.

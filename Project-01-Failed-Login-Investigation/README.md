Project Overview
This is a beginner-level SOC L1 investigation project based on a simulated security incident.

## Scenario
An employee account experienced 25 failed login attempts within 10 minutes from an unfamiliar IP address.

## Objective
Investigate the login activity, identify suspicious patterns, assess the potential risk, and document the findings.

## Tools Used
- Microsoft Excel
- Windows Authentication Logs (simulated)
- SIEM investigation concepts

## Investigation Steps
1. Review authentication logs.
2. Identify the affected user account.
3. Identify the source IP address.
4. Analyze failed login frequency and timestamps.
5. Check whether any successful login occurred.
6. Determine whether the activity resembles brute-force or password spraying.
7. Classify the alert and recommend appropriate action.

## Expected Deliverables
- Sample authentication log dataset
- Excel investigation and analysis
- Investigation findings
- SOC L1 incident report

## Important Note
All logs and investigation findings in this project are simulated for educational and portfolio purposes. They do not represent a real company incident.
